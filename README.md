# Food Orders Analysis and ELT Pipeline

## Project Overview
This project focuses on analyzing food order data using Python, Pandas, and MySQL. It includes data cleaning, data transformation, validation, and batch-based ELT processing.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- MySQL
- Jupyter Notebook

## Project Features
- Data loading and exploration
- Data cleaning and preprocessing
- Handling missing values and duplicates
- Data validation
- Batch-based data processing
- Storing cleaned data in MySQL
- Basic data analysis and visualization

## How to Run
1. Clone this repository.
2. Install dependencies using `pip install -r requirements.txt`.
3. Open the Jupyter Notebook.
4. Configure your MySQL connection.
5. Execute the notebook cells in order.
