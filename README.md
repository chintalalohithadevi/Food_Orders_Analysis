# Food Orders Analysis and ELT Pipeline

## Project Overview
This project focuses on analyzing food order data using Python, Pandas, and MySQL. It includes data cleaning, transformation, validation, and batch-based ELT processing.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- MySQL
- Jupyter Notebook

## Project Files
- `Food_Orders_Analysis_ELT.ipynb` – Main project notebook
- `food_orders.csv` – Original dataset
- `food_orders_cleaned.csv` – Cleaned dataset
- `food_orders_validation_report.csv` – Validation report
- `requirements.txt` – Required Python libraries

## Project Features
- Data exploration and profiling
- Missing value handling
- Data cleaning and transformation
- Data validation
- Batch-based ELT processing
- MySQL data storage
- Data analysis and visualization

## How to Run
1. Clone this repository.
2. Install dependencies using `pip install -r requirements.txt`.
3. Open the Jupyter Notebook.
4. Configure your MySQL connection.
5. Run the notebook cells in order.
